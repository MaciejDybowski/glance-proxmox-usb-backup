# Changelog

## Unreleased

- English/Polish panel and demo, including controls, application errors, locale-aware dates/numbers and accessible labels.
- Default panel language selected during installation (`--language en|pl`); upgrades preserve the existing choice or legacy Polish default.

## 2026.11.0 — Initial public release

- Glance-embedded USB backup panel for local Proxmox VMs and containers.
- Independent per-guest Notes and a durable sequential backup queue.
- UUID-checked mount/eject operations and optional safe eject after success.
- Native archive inventory with an offline, timestamped cache.
- Parameterized installation for exFAT, ext4, and XFS.
- Private workstation settings separated from public examples.
- Backend/API tests, browser scenarios, GitHub CI, and source-only export.
- Interactive GitHub Pages demo with fictional, in-memory data and simulated USB/backup operations.
